# Silero VAD

`silero_vad.onnx` (v5) from [snakers4/silero-vad](https://github.com/snakers4/silero-vad) (MIT, see LICENSE), taken
from the `silero-vad` 6.2.3 package (`silero_vad/data/silero_vad.onnx`). Run with onnxruntime by
`python/deep_audio.py`: the chance of speech in each 32 ms of the sound, at 16 kHz. It measures where speech is; it
decides nothing.
