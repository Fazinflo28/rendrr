# YuNet face detector

`face_detection_yunet_2023mar.onnx` from [opencv/opencv_zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)
(MIT, see LICENSE), run with OpenCV's `cv2.FaceDetectorYN` by `python/faces.py`. It measures where faces are for
`set_framing fitFaceTo`; it decides nothing.
